# PlasBench v0.2.3

A patch release that makes setting up the databases reliable on slow or unstable
connections. Scoring, rankings and the report are unchanged from v0.2.2.

## What changed

- **Database downloads resume.** MOB-suite's database (about 450 MB) and Platon's
  (1.69 GB) now download in a way that survives interruptions:
  - every byte already received is kept;
  - a dropped connection, a closed laptop or a later re-run continues where it stopped;
  - while the internet is down the download pauses and carries on when it is back;
  - the file is checked for the right size before it is used.

  MOB-suite's own tool (`mob_init`) cannot resume, so PlasBench now downloads its archive
  and then lets `mob_init` build the database from the finished file.
- **`plasbench check` installs Platon's database itself.** It no longer asks you to find a
  download link.
- **RFPlasmid works again.** Its CheckM dependency failed at start-up with
  `No module named 'pkg_resources'`; the install now keeps a compatible setuptools.
- **`plasbench test` passes on an installed release.** One documentation test looked for
  a GitHub workflow file that release downloads do not include.
- **New README Step 7d** explains the one-time setup for AMRFinderPlus, RFPlasmid's
  CheckM data and Plasmer's database.

## Upgrading from v0.2.2

```bash
cd ~ && curl -fL -O https://raw.githubusercontent.com/ubeffiong/plasbench/main/scripts/install_latest.sh && bash install_latest.sh
cd ~/plasbench-0.2.3 && conda activate plasbench
plasbench install-tools rfplasmid   # only if you use RFPlasmid: restores a working CheckM
plasbench check                     # installs any missing Platon / MOB-suite database
```

Then follow README Step 7d for AMRFinderPlus, CheckM data and Plasmer if you use them.
