# PlasBench v0.3.0

A feature release with two additions: you can benchmark any plasmid tool without changing PlasBench's code, and
you can do everything from a window in your web browser instead of the command line. Scoring, rankings and the
report are unchanged for the built-in tools.

## What changed

- **Bring your own tool.** Describe a reconstruction or classification tool in one small file, a
  `plasbench-tool.ini` manifest, and PlasBench installs it, runs it on every sample, converts its output, and
  scores, ranks and reports it beside the built-in tools. The manifest says:
  - what the tool is (its task and analysis track);
  - how to install it (conda, pip, an install script, or nothing);
  - how to run it, with placeholders such as `{contigs}`, `{graph}`, `{reads_1}` and `{outdir}` for each sample's
    files, or where outputs you already produced are;
  - how to read what it writes: a contig-to-bin table, contig labels with probabilities, a plasmid FASTA, a folder
    of FASTA files, or the tool's own small adapter.

  User tools get the same time limits, retries, outcome states, result reuse, database-leakage check and long-read
  circularity rule as the built-in tools, and their manifest, checksum and version are recorded with the results.
  New commands: `plasbench tools new | validate | list | show | add | install`, `plasbench install-tools NAME` and
  `plasbench run --tool NAME`. Guide: [docs/ADDING_TOOLS.md](../ADDING_TOOLS.md) and README section 5.11; one
  worked example per output format in `tools.d/examples/`.

- **The PlasBench window: `plasbench ui`.** Opens a page on this computer with:
  - a setup checklist (Python, Bash, conda, the core tools, databases, NCBI access, disk space) with an install
    action for anything missing, plus NCBI email and API key entry;
  - the tool catalogue, with install actions and a switch for whether each tool runs by default;
  - a form that writes, checks and installs your own tool's manifest;
  - every setting PlasBench reads, with its default and explanation, saved to `config/local.env`;
  - a New benchmark wizard (isolates, tools, resources, options, then a review of the exact command);
  - your own isolates, the bundled cohorts, runs and reports (open, export to PDF, rebuild), and a job list;
  - every `plasbench` command and option as a form, generated from the command line itself.

  Everything you start runs as an ordinary `plasbench` command whose output appears in the window's console. The
  page is served only to this computer and needs the session key printed with its address.

## Upgrading from v0.2.3

```bash
cd ~ && curl -fL -O https://raw.githubusercontent.com/ubeffiong/plasbench/main/scripts/install_latest.sh && bash install_latest.sh
cd ~/plasbench-0.3.0 && conda activate plasbench
plasbench ui        # optional: the window
```

Nothing needs reinstalling: existing results, databases and settings are reused.
