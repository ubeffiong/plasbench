# PlasBench v0.2.0

Released 2026-11-10. Previous release: [v0.1.5](v0.1.5.md) (2026-09-10).

v0.2.0 changes how PlasBench ranks tools, what it measures, and how the report reads. It is a minor version because several outputs and rankings differ from v0.1.5
(see **Upgrading from v0.1.5**). It adds about 75,000 lines over 365 files and 32 merged pull requests (#5 to #38), and ships with a sample HTML report you can open
without running anything.

## Highlights

1. **A defensible headline.** Reconstruction tools are ranked on length-weighted binning F1 (short-read) or on isolate-level CPRR, the share of truth plasmids
   reconstructed correctly (long-read and hybrid), with confidence intervals that respect non-independent isolates. Classifiers are ranked on their own task, and the
   two are never mixed, including in the recommendation.
2. **A trustworthy reference standard.** Each truth assembly is graded in tiers by how it was built, labels are confirmed with evidence, ambiguous replicons are excluded
   rather than guessed, and every scoring decision is pre-registered and hash-frozen.
3. **A rebuilt HTML report** that opens on an Overview, shows one view at a time, explains every analysis with a **?** help button, draws interactive circular plasmid
   maps and 3D figures, and downloads each isolate's best reconstruction with one click.
4. **A much wider set of measurements**, each advisory and none able to change the headline silently: sequence accuracy, feature and gene-order preservation, bin quality
   tiers, graded recovery, a negative control, calibration, power, scenarios, a contig-level layer with an independent second scorer, and AMR placement.
5. **Faster and sturdier runs**: exact statistics without the old overhead, fingerprinted tool re-use, preserved downloads, databases stored once per machine, and tools
   that cannot start are caught at setup instead of scoring as zero.

## Upgrading from v0.1.5

Read this first: the following change what you get from the same inputs.

- **Rankings and headline columns differ.** The primary endpoint is now length-weighted binning F1 for binning-capable tools (`lw_bin_f1`), with CPRR as secondary; long-read
  and hybrid reconstruction are ranked on isolate-level CPRR; classifier-only tools are ranked on a separate classification track by base-level F1. Leaderboards gain `task`,
  `ranking_metric`, `ranking_score` (with CI), `ranking_species_basis`, `cprr` and `mean_lw_bin_f1`.
- **Recommendations are reconstruction-only.** `benchmark.recommendations.tsv` has a last column `task`; classifiers are no longer compared with reconstruction tools in one
  "recommended overall" line. `select_operational_method.py --task all` keeps the old pooled behaviour and warns.
- **The Mash nearest-reference screen no longer claims novelty** (experimental, off by default): `known_cluster` is now `close_reference_match`, `novel` is now
  `no_close_reference`, and `confidence_score` is now `distance_margin`. Anything reading the old labels must be updated.
- **`make_truth.py` no longer guesses CHROMOSOME** for a sequence it cannot label: it writes `REVIEW`, which stage 2 refuses, instead of silently biasing precision and recall.
  `ALLOW_DEFAULTED_TRUTH=1` restores the old behaviour.
- **Old tool results re-run once**: stage 4 re-uses a result only when its fingerprint (executable, adapter, database row, settings, inputs) matches; markers from earlier
  releases re-run (`REUSE_UNFINGERPRINTED=1` re-uses them unchecked).
- **MOB-suite lives in its own pinned environment** (it needs `pandas<=1.5.3`); databases move to a per-machine store (`PLASBENCH_DB_DIR`, default `~/.plasbench/databases`,
  `env/preserve_databases.sh` moves existing ones and leaves links, deleting nothing).
- **Report ids still work.** Related sections are merged into tabbed groups, but every old section id still lands on its tab. Two things were removed as duplicates: the
  "Automated interpretation" section (it repeated *Start here*) and the "Data in this report" table (the Artifact explorer lists every file, now with a description). A section that
  only says "Not run" is not shown; Run metadata lists every analysis that was not run, with its reason. The interactive cohort dashboard is now optional
  (`REPORT_EMBED_DASHBOARD=1`, about 1 MB).

## What changed, by area

### Ranking, statistics and the reference standard (#5, #7, #8, #14, #21)
- Primary endpoint `lw_bin_f1`; secondary CPRR with pre-specified `CPRR_MIN_COVERAGE`, `CPRR_MIN_SHARE`, `CPRR_MIN_IDENTITY`; track-specific endpoints; CPRR robustness analyses.
- Reference tiers 1 to 3 from truth provenance (long-read-first versus short-read-first, polished with the benchmark's own reads or not). Tier-3 truth leaves the headline and
  becomes a sensitivity analysis.
- Evidence-based truth labels (plasmid markers, rRNA genes via barrnap, long-read support); conflicting replicons are AMBIGUOUS and excluded from scoring.
- Species-balanced headline, cluster-aware bootstrap and paired permutation tests that resample whole BioProjects, Wilcoxon with Holm correction, equivalence within a delta,
  ranking sensitivity (Kendall tau), statistical power, database-leakage screens, and reproducibility across runs.
- Pre-registration (`config/prereg.tsv`, SHA-256 freeze and verify), outcome states (completed, failed (tool), failed (resource), infrastructure failure, not applicable),
  and a recommender evaluation (leave-one-study-out, unseen taxa, regret, "benchmark only" verdicts).

### Measurements added (#9, #12, #11, #14, #17, #19, #20)
- Contig-level classification with MCC, ARI, assembly-aware binning and micro averaging; MCC and F-beta with abstention; graded recovery (50%, 90%, complete and circular);
  zero-plasmid negative control; trivial baselines and calibration.
- Sequence accuracy and missing regions from alignment CIGARs; feature and gene-order preservation; bin quality tiers; computational performance; scenarios; an optional
  five-dimension composite; a weighted 17-metric scorecard with bands, shown beside the leaderboard and never replacing it.
- Independent second scorer for the contig layer (alignment-free k-mer labels); PlasEval-style bin agreement; GAEMR-style repeat and depth QC of the truth; assembly adequacy.
- Tool support: an optional plsMD wrapper, a PlasBin-flow output adapter, ISFinder evidence, a replicon baseline.
- Cohort: the locked **`public-v3`** panel (98 isolates, 66 new long-read-first isolates, one per BioProject, across six species) and verified tool-database release dates.

### The HTML report (#24, #25, #26, #30, #31, #32, #35, #36, and this release)
- **Layout**: fixed top bar and left rail, one view at a time (Overview, Recommendation, Figures, Plasmid maps, Detailed results, Data and reference quality, Methods and limits,
  Scorecard (exploratory), Appendix), phone-friendly menu, hash links for every old id, and a Print / Save PDF that writes every view in order with a cover and contents.
- **Figures**: reconstruction ladder, tool-by-metric heatmap, CPRR distributions and forest plot, precision-recall, and an interactive 3D landscape, each with a setup panel
  and SVG, PNG or CSV export. 3D views for the contig layer, recommender and AMR placement.
- **Plasmid maps**: one interactive circular map per truth plasmid (genes, one ring per tool, structural events, GC content and skew), a linear reference-versus-reconstruction
  pane, and a reconstruction evidence explorer.
- **Explanations**: a green **?** on every section and tab opens a plain-language help dialog in six parts (what it shows, the data used, how it was made, how to read it, why it
  matters, what to keep in mind); notes are hover "i" tooltips; a searchable glossary replaces forty headings.
- **Which tool recovered which plasmid**: a per-isolate matrix with an isolate filter that re-scores the card, scorecard and matrix for one isolate, and a small **FASTA**
  button per isolate that downloads its selected reconstruction when the report sits in its results folder and is greyed out when the file cannot be reached.
- **Honest sections**: duplicates merged (one home per result), Not-run sections listed once in Run metadata, build-time display names for tools, lazy-loaded explorers.
- **A sample report** (`docs/sample_report/benchmark.report.html`, offline synthetic data) linked from the README. Every demo run (`plasbench demo`, `test/run_demo.sh`) replaces it
  with the newest demo report (skipped when the folder is absent, `PLASBENCH_SAMPLE_REPORT=0`, or the report is incomplete or holds a local path) (#38).
- Fixed in this release: a 3D chart drawn flat after a Not-run tab was pruned (#35).

### Operational use (#28, #29)
- `PRESERVE_DOWNLOADS=1`: reads and NCBI records are checksummed and made read-only; a later run with the same `DATA_DIR` downloads nothing.
- A tool that is installed but cannot start is reported as `[BROKEN]` at setup; import failures are infrastructure failures, not F1 = 0.
- A run killed for lack of memory is a **resource** failure (`failed_resource`), like exit 124/137, and `--resource-failures exclude` can drop it (#34).

### Performance (#16, #27)
- Rectangular bin matching (same optimum, 400 bins by 20 plasmids in 0.02 s); exact statistics without `Fraction` objects (bit-identical results); fingerprinted tool re-use; one
  minimap2 index per sample; the capability registry read once per stage; streaming and parallel downloads. Details: [docs/PERFORMANCE_AUDIT.md](../PERFORMANCE_AUDIT.md).

### Fixes
- Truth labelling, ranking fairness, leakage visibility and rank-robustness audit fixes (#5, #8); `benchmark.species.tsv` now lists a tool that failed on every sample (#9);
  install wiring for mash, samtools, barrnap and the annotation callers (#15); the `repeat_rich` scenario tag now fires on real annotation; MOB-suite pandas incompatibility;
  PDF export from WSL; leftover conflict markers in the changelog.

### Documentation
- [Scientific guide](../SCIENTIFIC_GUIDE.md) for domain experts (every metric and statistical procedure, the cohorts, how to read each output), a question-bank FAQ, the pipeline
  workflow figure in the README, and a step-by-step lab guide.

## Known limits

- Every number in the shipped sample report is synthetic (the offline demo). The project still has no real-data results to quote; the cohort runs are yet to be done.
- Grade-band thresholds other than identity are proposed defaults, and SNP concordance and structural-variant F1 are "not available" because no truth variant set exists.
- The matrix download buttons check the file with a script request when the report is opened from a local file; a browser may log one harmless parse error per file.

## Install or upgrade

```bash
sha256sum -c plasbench-0.2.0.tar.gz.sha256
```

Existing installations: `plasbench upgrade`.
