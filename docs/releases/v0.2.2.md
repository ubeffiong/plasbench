# PlasBench v0.2.2

A patch release. The tool install step no longer stalls on Trycycler. Scoring, rankings
and the report are unchanged from v0.2.1.

## What was wrong

During `install_latest.sh --tools` (or `plasbench install-tools all`), the `trycycler`
step tried to add Trycycler, Flye and Medaka to the main `plasbench` environment.
Medaka brings a PyTorch stack, and fitting it among everything already installed there
kept conda solving for 45 minutes and more without finishing.

## What changed

- Trycycler and Medaka now get their own environment, `plasbench-trycycler`, where the
  same packages install in about 4 minutes. Wrappers for `trycycler`, `medaka` and
  `medaka_consensus` go into the main environment, so you still only activate
  `plasbench`.
- The main environment's own `flye` (installed by the long-read profile) is not changed.

## If an install is stuck on "Conda is solving/linking dependency tools: trycycler flye medaka"

Stop it with Ctrl+C (nothing has been installed yet while conda is still solving), then
run the installer again:

```bash
cd ~ && curl -fL -O https://raw.githubusercontent.com/ubeffiong/plasbench/main/scripts/install_latest.sh && bash install_latest.sh --tools
```
