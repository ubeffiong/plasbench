# PlasBench v0.2.8

Released 2026-09-08.

## Evidence-calibrated metagenomic expansion

- Adds a separate graph-aware metagenomic scoring and reporting track with
  three-class plasmid, chromosome, and virus truth; global bin matching; split,
  merge, contamination, and uncertainty diagnostics; and a dedicated HTML
  dashboard.
- Adds governed cohort templates, BMock12 checksum-pinned materialization,
  optional mobilome-evidence import, and explicit guardrails that prevent
  metagenomic results being presented as isolate rankings, host linkage, or
  clinical confirmation.
- Adds installer registry coverage for supported optional reconstruction and
  classification tools, while correctly retaining unpinned or unvalidated
  external runtimes as planned rather than fabricating automation.

## Reliability and presentation

- Rejects malformed BMock12 truth memberships, clearly fails a truth-backed
  metagenomic score run with no normalized predictions, and protects embedded
  report metadata from ending the dashboard script.
- Adds a deterministic, offline metagenomic demo fixture showing reconstruction
  quality trade-offs, a three-class classifier, uncertainty, and non-scoring
  mobilome evidence.
- Adopts the full project title: **PlasBench: A Reproducible,
  Evidence-Calibrated Benchmarking Framework for Plasmid Reconstruction Tools**.
  The stable CLI remains `plasbench`.

## Compatibility

Existing isolate workflows and `plasbench` commands remain compatible. The
metagenomic track is intentionally separate and does not combine ranks or
recommendations with isolate results. Shared data directories are retained by
the normal upgrade flow.

## Verify

Download the release archive and checksum together, then run:

```bash
sha256sum -c plasbench-0.2.8.tar.gz.sha256
```
