# PlasBench v0.5.0

Released 18 November 2026. This release changes some scores, so **read "Scores that change" before comparing with a v0.4.1 result.** The full list of changes since v0.4.1 is in the [changelog](../../CHANGELOG.md); the test evidence is in [docs/QA_RESULT_2026_11_18.md](../QA_RESULT_2026_11_18.md).

## If you are on v0.4.1

Run `plasbench upgrade` (or `cd ~/PlasBench && ./update.sh`). Your studies, settings, databases and tools are kept. Reuse of tool results is fingerprinted, so an upgrade re-runs the tools; re-score any result you want to put beside a new one.

## Scores that change

These come from the independent audit of 17 November 2026 (53 findings, status per finding in [docs/AUDIT_2026_11_17_STATUS.md](../AUDIT_2026_11_17_STATUS.md)). Re-score old results before putting them beside new ones.

- **NMI, Variation of Information and ARI penalise a missed plasmid.** Sequence of a true plasmid that no bin covers is now treated as unassigned (each base its own cluster). Before, one wholly missed plasmid formed a cluster that matched it one-to-one and scored a perfect 1.0, 0.0, 1.0.
- **An AMR gene on a record that is in no bin is `unassigned_contig`**, not `correct_plasmid`. **Gene recovery is the union of alignments** in both scorers; a gene split across records is recovered but reported as `unassigned_contig`.
- **A binner that bins nothing has blank precision** (as the base scorer) with recall and F1 of 0, and the bin scorer skips secondary alignments and checks target lengths against the truth.
- **Truth provenance reads the real NCBI wording** (`OXFORD_NANOPORE`, `IlluminaMiSeq`, misspelt Unicycler, HGAP, and the Illumina polishers Polypolish, Pilon and others). 218 genuine short-read-first assemblies were `unknown` and nine Illumina-polished ones were called independent. public-v4 and the negative controls are relabelled and their lock hashes updated; `python/relabel_cohort_provenance.py` reproduces it.
- **Intervals for proportions are clipped to [0, 1]** (paired differences to [-1, 1]). The method and its under-coverage in some designs are unchanged and documented in `docs/STATS_VALIDATION.md`.
- **A sample with no provenance record is no longer assumed identity-valid**: unknown is never treated as independent.

## What is new since v0.4.1

**Evidence and ranking**
- **public-v4**, a 7,227-isolate verified validation panel, with a selection report and balanced `--max-isolates`; a short-read QC pre-check whose **thresholds are now frozen from a real-read pilot** (`docs/THRESHOLD_FREEZE.md`).
- **Independent-truth runs**, negative-control discovery (plasmid-free isolates), a stratified studentised bootstrap, and the **interval decision pre-registered** (`bootstrap_t` for a species-balanced mean, simulation re-run). The pre-registered scoring decisions are confirmed and changeable in a controlled way (`prereg_admin`).
- **Truth-exclusion sensitivity**: the headline with and without the replicon-database exclusion, for base F1 and for the binning F1 and CPRR headlines.
- A configurable **leakage screen**; **ranking stability**, **assembler sensitivity**, a **reference evidence audit**, candidate multiplicity and the 215-question reviewer assessment; **PlasmidEC** as a benchmarked tool; PLSDB novelty, performance drivers and plasmid-free controls.
- **Publication cohorts** and a comparison of PlasBench results with a paper's published outcomes (including repeat-aware PlasEval dissimilarity, checked against the original program).

**Using it**
- **Your own isolates**: a sheet template, a folder scan, a quick test and guided repair of every error.
- **Studies live in a working directory** with one git repository for all of them (`git init` in the working directory, a managed ignore block, per-study notes, tags, rename, copy, archive, delete and zip bundle export/import with checksums).
- The window shows run sessions (ongoing, needs attention, completed), resume, reconnect and keep-running quit, plus `stalled`, `retrying` and `completed_with_warnings` states, Forget, remote Remove, Create on GitHub and git sign-in.
- Run reports are served under a sandboxing Content-Security-Policy; terminal commands are redacted before logging; the commit secret scan covers all text files up to 5 MB.

**Reliability**
- Per-run temp folders and a **run lock with a heartbeat**; adapters fail with "no output from <tool>" when only a log was written; process-group cancel and orphan recovery; stage 4 exits 4 when every tool failed; stage 8 only uses predictions from the current run; a stage-4 database and prediction-FASTA pre-flight; atomic table writes; timeouts on every helper subprocess; per-run thread and timing records.
- A **run-table consistency check** and report input validation: a leaderboard paired with different scores is refused, and a small or empty shared-sample set is flagged.
- The test runner counts skipped checks (`REQUIRE_NO_SKIPS=1` fails on any), CI runs on Python 3.9, 3.11 and 3.13 with actions pinned to commit SHAs and read-only permissions, and the real-tool checks use real reads for plasmidSPAdes.

## A real-data evaluation ships with this release

`results_real_cohort1/` is a real run, not the demo: **10 public isolates with downloaded reads and deposited reference assemblies** (seven urinary *E. coli*, two AR Bank isolates and one *Salmonella*), scored for the three real tools `mob_recon`, `platon` and `plasmidspades` and a coverage baseline. It shows the pipeline running end to end on real data and gives a descriptive comparison of those tools. It is **not a ranking**: only 1 of the 10 references reaches reference Tier 2, so the headline ranking rests on one isolate. Details and the numbers are in `results_real_cohort1/README.md`. It was built with PlasBench 0.2.3 and has not been rebuilt with this release.

## Known limits

- **Not fixed:** the download-size and timing figures in the guides are estimates; a measured pilot is still needed (AU-034).
- **Partly fixed:** real-binary checks cover only `mob_recon`, `platon` and `plasmidspades` (13 tools are tested against stand-ins only); only the gplas2 checksum is pinned in `config/download_checksums.tsv`; some FASTA, PAF and table readers are not yet on the shared validated readers; SIGKILL and pid reuse still limit the run lock (a stale heartbeat now covers most of it); there is no default tool timeout (`PLASBENCH_TOOL_TIMEOUT_PRESET=generous` is an opt-in preset). The complete list is in [docs/AUDIT_2026_11_17_STATUS.md](../AUDIT_2026_11_17_STATUS.md).
- The window and the report sandbox were verified by headers, static page checks and tests, **not in a real browser** for this release.
- The 19 checks the full suite skipped (16 need `node`, 2 are opt-in real-browser tests, 1 needs a PlasEval checkout) did not run; see the QA result.
