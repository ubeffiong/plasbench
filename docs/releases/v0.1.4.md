# PlasBench v0.1.4

Released 2026-09-08 from source commit `cc5884c`.

This release supersedes the now-removed v0.2.5 through v0.2.8 tags from an
earlier numbering pass; their changes are folded into the summary below.

## Highlights

- A separately executable metagenomic scoring/reporting track
  (`plasbench metagenomics`, or `plasbench run --mode metagenomics`) with
  three-class plasmid/chromosome/virus truth, global bin matching, and
  split/merge/contamination diagnostics -- kept structurally separate from
  isolate rankings, host linkage, and clinical confirmation.
- An auditable tool-installer registry (`plasbench install-tools list`,
  `plan`, `validate`) covering every supported, non-demo adapter.
- An external-benchmark importer that preserves source data, checksums, and
  truth-definition boundaries rather than mixing external scores into
  native results, plus an `amr_context` decision profile.
- Strict reference-recovery-rate metrics, nested-validation model cards, and
  a round of HTML dashboard fixes (auto-sized frames, balanced panels,
  clearer heatmap/report handoff).
- The project's public identity was refreshed to **PlasBench: A
  Reproducible, Evidence-Calibrated Benchmarking Framework for Plasmid
  Reconstruction Tools** -- the stable `plasbench` command is unchanged.
- A complete release guide (`docs/RELEASES.md`) and `CHANGELOG.md`.

## Install or upgrade

```bash
sha256sum -c plasbench-0.1.4.tar.gz.sha256
```

Existing installations: `plasbench upgrade`.

## Container

```bash
docker pull ghcr.io/ubeffiong/plasbench:v0.1.4
docker run --rm ghcr.io/ubeffiong/plasbench:v0.1.4 plasbench --version
```

A software release confirms packaging and automated test coverage; it does
not prove a reconstructed plasmid is biologically closed or universally
best. Preserve the HTML report, `run_manifest.json`, cohort lock, and
tool/database versions with downstream work.
