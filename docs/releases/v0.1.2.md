# PlasBench v0.1.2

Released 2026-09-05 from source commit `c4bd8f0`.

This release supersedes the now-removed v0.1.6 through v0.1.9 tags from an
earlier numbering pass; their changes are folded into the summary below.

## Highlights

- `plasbench init-local` stages your own FASTQ reads and reference into the
  pipeline, writing the truth table and sample-sheet row. Unlabelled
  sequences are written as `REVIEW` rather than guessed.
- Two input validators run before any tool starts: staged reads (missing,
  empty, not actually gzipped, mates out of order) and the truth table
  (unmatched ids, unlabelled sequences, bad `molecule_type`, tabs vs.
  spaces, length mismatches). These used to be silent failures that moved
  the leaderboard without an error.
- `THREADS`/`MEMORY_GB` now default to 80% of the detected machine's
  cores/RAM instead of a fixed value.
- Databases are checked for presence before being re-downloaded (previously
  every re-run re-fetched ~450 MB from zero); a partial download is reported
  as incomplete, never mistaken for a working install.
- A failed download no longer aborts the whole cohort -- failures are
  recorded per sample with automatic retry, and the stage aborts only when
  every sample fails.
- Cohort downloads are estimated and confirmed before fetching.
- Plassembler support on the long-read/hybrid track, with a circularity
  guard so truth independence is never silently assumed.

## Install or upgrade

```bash
sha256sum -c plasbench-0.1.2.tar.gz.sha256
```

Existing installations: `plasbench upgrade`.

## Container

```bash
docker pull ghcr.io/ubeffiong/plasbench:v0.1.2
docker run --rm ghcr.io/ubeffiong/plasbench:v0.1.2 plasbench --version
```
