# PlasBench v0.4.1

A fixes-only release for problems found on first install and first launch on Windows/WSL. **Scores and rankings are the same as v0.4.0.** Full detail is in the [changelog](../../CHANGELOG.md#041---2026-11-16).

## If you are on v0.4.0

Run `plasbench upgrade` (or `cd ~/PlasBench && ./update.sh`). Your studies, settings, databases and tools are kept.

## What is fixed

- **The desktop icon starts PlasBench.** It used to exit on conda's activate scripts (`SYS_SYSROOT: unbound variable`).
- **`plasbench install-tools all` no longer fails when one optional tool cannot install.** On a small PC the Trycycler environment is killed for memory; it is now listed with how to retry, and the memory advice for WSL is printed. Retry it alone with `plasbench install-tools trycycler`.
- **A failed download says why**, and for a DNS failure explains the fixes. `bash install_latest.sh --archive plasbench-<version>.tar.gz` installs a release file you downloaded elsewhere, with no network.
- **The window uses its own clean browser profile** (extensions, sync and notifications off), and the session-key page explains how to get the full link again.
- **Study repositories keep per-sample folders, sequence and clinical files out of git**, and the commit scan blocks more patient-identifier columns.
