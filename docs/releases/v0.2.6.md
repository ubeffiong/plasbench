# PlasBench v0.2.6

Released 2026-09-08 from source commit `a398380`.

## Highlights

- Adds an auditable installer registry for all supported non-demo adapters.
  Use `plasbench install-tools list`, `plan`, and `validate` to see what is
  available, what will run, and whether registry coverage is complete.
- Adds safe external-evidence import and candidate-quality dataset workflows.
  Imported evidence retains its source, checksums, and truth-definition
  boundary; it is not silently combined with native PlasBench scores.
- Improves first-run guidance and project-root errors, so users receive a
  direct recovery command rather than a late, confusing workflow failure.
- Adds regression coverage for installer completeness, external evidence,
  candidate-label safety, README installation paths, and CLI launch context.

## Install or upgrade

For a new Linux/WSL installation, use the latest-release installer in the
[README](../../README.md). Existing installations can run:

```bash
plasbench upgrade
```

The upgrade reuses the shared data directory. It does not re-download existing
cohorts, reads, or databases merely because the application version changes.

To install this exact release manually, download both assets from the GitHub
Release page and verify before extracting:

```bash
sha256sum -c plasbench-0.2.6.tar.gz.sha256
```

## Container

Use the immutable image for repeatable work:

```bash
docker pull ghcr.io/ubeffiong/plasbench:v0.2.6
docker run --rm ghcr.io/ubeffiong/plasbench:v0.2.6 plasbench --version
```

Use `:latest` only when deliberately following the newest release.

## Verification

The release workflow built the Python distribution, validated the release
archive and checksum, and published the GitHub archive and GHCR image. The
source tree's full offline test suite and demo also pass. PyPI availability
must be verified separately on its public project page before being claimed.

## Important scope

This is a benchmarking and reporting release, not a universal claim that one
tool is best for every isolate. A high score does not prove nucleotide-perfect
closure or biological validity. Preserve the run report, `run_manifest.json`,
cohort lock, tool/database versions, and confirmation flags with downstream
results.

`gplas2` remains source-runtime-only pending a reproducible upstream runtime
and validated classifier provenance. It is intentionally not presented as a
one-command dependency install.
