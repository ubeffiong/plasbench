# PlasBench v0.1.3

Released 2026-09-07 from source commit `7c25ed0`.

This release supersedes the now-removed v0.2.0 through v0.2.4 tags from an
earlier numbering pass; their changes are folded into the summary below.
Nothing here is on by default -- an existing cohort run behaves exactly as
before unless a new flag is switched on.

## Highlights

- Three new long-read/hybrid tools: `hybracter_long`, `hybracter_hybrid`, and
  `trycycler_mob_recon` (a second independent long-read assembly path
  alongside Flye+MOB-Recon and Plassembler).
- Each tool is now scored under its own declared `analysis_track`, so one
  run correctly scores short-read, long-read, and hybrid tools together.
- The circularity guard (truth independence from long reads) now applies to
  all five long-read/hybrid tools, including retroactively to
  `flye_mob_recon` -- a real behavior change: an existing cohort lacking
  `truth_independent_of_long_reads=yes` will now correctly skip samples it
  previously scored against their own input.
- Three opt-in ML classifiers (`genomad`, `plasme`, `plasgraph2`) and a new
  `pr_auc` metric that sweeps every distinct probability threshold where an
  adapter publishes per-record probabilities.
- A read-quality ladder (the long-read analog of the depth ladder), a
  leave-one-study-out decision-support model, and `plasbench upgrade`/
  `update.sh` for one-command version upgrades that reuse shared data.

## Install or upgrade

```bash
sha256sum -c plasbench-0.1.3.tar.gz.sha256
```

Existing installations: `plasbench upgrade`.

## Container

```bash
docker pull ghcr.io/ubeffiong/plasbench:v0.1.3
docker run --rm ghcr.io/ubeffiong/plasbench:v0.1.3 plasbench --version
```
