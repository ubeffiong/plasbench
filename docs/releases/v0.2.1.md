# PlasBench v0.2.1

A patch release. `plasbench install-tools all` now completes on a fresh machine.
Scoring, rankings and the report are unchanged from v0.2.0, so v0.2.0 results stay
comparable.

## What was wrong

Three optional tools could not be installed into the main `plasbench` environment,
which runs Python 3.12:

| Tool | Why it failed |
|---|---|
| PlaScope | its pinned Centrifuge 1.0.3 is built only for Python 3.6 or older |
| Plasmer | its channel (`iskoldt`) publishes a Python 3.10 build only |
| PlasmidHunter | every PyPI release requires Python 3.10 (`No matching distribution found`) |

`install-tools all` carried on past them but exited with an error, and the three tools
were reported unavailable at run time.

## What changed

- Each tool gets its own environment, `plasbench-plascope` (Python 3.6),
  `plasbench-plasmer` (Python 3.10) and `plasbench-plasmidhunter` (Python 3.10). Small
  wrappers in the main environment run them, so `conda activate plasbench` is still all
  you need. This is the same arrangement MOB-suite has used since v0.2.0.
- PlasmidHunter is pinned to 1.4 with `setuptools<81`, because it imports
  `pkg_resources`, which setuptools 81 removed.
- The installer now checks that each of these tools actually starts. An environment that
  exists but does not start is rebuilt.
- Plasmer is installed without Anaconda's commercial `defaults` channel.

## Upgrading from v0.2.0

```bash
plasbench install-tools plascope
plasbench install-tools plasmer
plasbench install-tools plasmidhunter
```

or simply `plasbench install-tools all`. Databases are unaffected: PlaScope's and
Plasmer's databases are still downloaded separately, as before.
