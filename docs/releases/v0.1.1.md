# PlasBench v0.1.1

Released 2026-09-04 from source commit `8cd3a58`.

This release supersedes the now-removed v0.1.1 through v0.1.5 tags from an
earlier numbering pass; their changes are folded into the summary below.

## Highlights

- Corrected release build and CI, and introduced the packaged install-archive
  distribution (`plasbench-<version>.tar.gz` + `.tar.gz.sha256`, installed
  with `./install.sh --tools`).
- Fixed three defects that broke a fresh install on Linux: CRLF line endings
  in release archives, a `public-v2` cohort lock regenerated and re-verified
  against NCBI, and `plasbench run` exiting 2 on Python <= 3.12 with no stage
  numbers given. `install.sh` now bootstraps Miniforge itself when needed.
- Fixed a micromamba prefix-resolution bug in `plasbench install-tools`, and
  stopped `install-tools all` from pulling the incompatible bioconda `gplas`
  package.
- **Install-critical fix**: `env/setup_conda.sh` no longer destroys an
  existing environment (including MOB-suite's database) when re-run against
  a working install.
- Added three Galaxy tool wrappers (align/score/aggregate) with a real
  bioconda recipe.

## Install or upgrade

```bash
sha256sum -c plasbench-0.1.1.tar.gz.sha256
```

Existing installations: `plasbench upgrade`.

## Container

```bash
docker pull ghcr.io/ubeffiong/plasbench:v0.1.1
docker run --rm ghcr.io/ubeffiong/plasbench:v0.1.1 plasbench --version
```
