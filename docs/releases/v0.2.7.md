# PlasBench v0.2.7

Released 2026-09-08.

## Documentation and citation patch

- Adds a complete release guide covering GitHub archives, PyPI, versioned
  containers, verification, upgrades, rollback, release scope, and maintainer
  checks.
- Adds a changelog and a reusable GitHub Release-page template, so releases
  contain usable installation and scientific-scope information rather than
  only an automatically generated commit list.
- Updates `CITATION.cff` to version `0.2.7` and the current release date.
- Corrects stale guidance that said PyPI Trusted Publishing was not yet
  configured; releases now document the verified publication route.

## Compatibility

There are no pipeline, scoring, tool-adapter, or data-schema changes relative
to v0.2.6. Existing installations can upgrade normally; the shared data
directory is retained and reused.

## Verify

Download the release archive and checksum together, then run:

```bash
sha256sum -c plasbench-0.2.7.tar.gz.sha256
```

For complete guidance, see the [release guide](../RELEASES.md).
